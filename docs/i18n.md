# 国际化（i18n）：新增语言的接触面清单

> 当前支持五种语言：en / zh（简体）/ zh-TW（繁体）/ ja / ko。
> 新增第 6 种语言时必须改动的**全部**位置——漏一处就会出现「半中半英」的界面。

## 语言代码约定

- 代码统一用 `zh`、`zh-TW`、`ja`、`ko` 这样的 BCP-47 短码；文件内的键名、
  `<html lang>`、`documentElement.lang` 都用它。
- 默认语言：首次启动按 Electron 上报的 locale 匹配
  `SHIPPED_LOCALES = ['en','zh','ja','ko','zh-TW']`（`src/main/state.js:29`），
  精确匹配 → 失败取 `zh` 前缀 → 再失败回 `en`。用户手动选择后经
  `set-lang` 持久化，`defaultLocale()` 不再生效。

## 必须改的 5 处

| # | 文件 | 做什么 |
|---|------|--------|
| 1 | `src/renderer/i18n.js` | `LANGS` 数组加一行 `{code,label,native,dir}`；`S` 对象加一个与 `en` 键集完全相同的语言块。缺失键自动回落英文（`t()` 里 `S.en[key]`），但**建议零缺失**——测试会数重复次数 |
| 2 | `src/shared/feature-i18n.js` | 主进程侧词典（安装/恢复/托盘/对话框）。`aliases` 机制把 zh-TW 映射到 zh；`dialogStrings` 块（:196）单独有一份五语键，别漏 |
| 3 | `src/renderer/overlay-panel.js` | 游戏内面板词典：新增 `OL_XX`（~110 键）+ 挂进 `OL_MAPS`（:549）+ `olLang()`（:554）加前缀分支。动态子串替换组 `OL_XX_PARTS` 也要一份并挂 `OL_PARTS_MAPS`（:595，ko 为 null） |
| 4 | `src/renderer/overlay-gallery.js` | 画廊词典：`GALLERY_XX`（en 键 → 译文，:4-12）+ 挂进 `GALLERY_MAPS` + `olLang()`（:4）加分支。`text(en)` 按英文原文查表 |
| 5 | `build/installer.nsh` | 卸载弹窗：每种语言一行 `LangString uninstallGameNotice <LCID> "…"`。**必须用数字 LCID**（如 2052），不能用 `${LANG_*}`——自定义 include 的时点这些 define 还没定义，会触发 7025 warning treated as error |

同时核对 `package.json` 的 `build.nsis.installerLanguages`（:97）——它决定
NSIS 语言表加载哪些语言；**表内每种语言都必须有对应 LangString**，
否则 6040 warning treated as error（这就是当时越南语报错的根因）。
新语言要把自己的代码加进这个数组（如 `fr_FR`），否则要么补全部 26 种
捆绑语言的 LangString，要么接受构建失败。

## 术语对照（保持跨文件一致）

| en | zh | zh-TW | ja | ko |
|---|---|---|---|---|
| overlay | 叠加层 | 疊加層 | オーバーレイ | 오버레이 |
| add-on | 附加组件 | 附加元件 | アドオン | 애드온 |
| Restore originals | 还原原文件 | 還原原始檔 | 元に戻す | 원본 복원 |
| console | 主控台/控制台 | 主控台 | コンソール | 콘솔 |

术语表在 i18n.js 与 feature-i18n.js、overlay-panel.js 三处必须用词一致；
产品名（DLSS、ReShade、RenoDX、OptiScaler、Feeder）保留英文不翻译。

## zh-TW 特例

- 主词典（i18n.js）里 zh-TW 块存在但**引用键**：测试断言
  `(i18n.match(/overlayNotForRoute: \(why, api\) =>/g)).length === 4`
  （en/zh/ja/ko 四个函数 + zh-TW 引用键），见 release-228.test.js:120-121。
- overlay-panel 与 gallery 的 zh-TW 是**完整独立词典**（不走引用），
  术语按上表对齐（疊加層/還原原始檔/連線/解析度…）。

## 验证清单

1. `pnpm test` 全绿（274 用例；i18n 相关断言会数词典块数量）。
2. 启动应用 → Settings 切到新语言 → 首页/游戏/历史/设置/关于五页全部无英文残留。
3. 触发一次安装/卸载弹窗（dialogStrings）与卸载器（NSIS LangString）。
4. 游戏内打开 overlay 面板与画廊，确认无英文残留、无 U+FFFD 乱码
   （传输损坏 historically 出现在韩文/日文多字节字符上）。
5. `defaultLocale()` 的 `SHIPPED_LOCALES` 与 installerLanguages 同步补齐。
